# WSwavelet 0.1.0

Initial package release accompanying Sanyal (2026), *Axioms*, 15(9), 678.

The release provides the resolution-adaptive Wendland-Semicircle Bayesian
wavelet denoiser, Gaussian and Laplace working-likelihood options, independent
posterior and kernel evaluators, robust noise estimation, shrinkage-curve
inspection, and numerical diagnostics.
